# Style reference index — 40 entries

Use this index to locate a candidate, then read only the relevant card. These seven browsing groups overlap: a layout, surface or asset treatment can accompany a visual tone. They are not mutually exclusive whole-site templates. Keep the current theme unless the task calls for reconsideration. For open choices, use the [selection rules](../style-selection.md).

The entries retain the labels of eight user-provided static boards (five labels each). Cards cite the board number and separate visible cues from suggested adaptations. Original images remain in the authoring archive; this package needs no local Downloads folder or remote website. No board establishes exact tokens or working behavior. The labels are reference vocabulary, not a claim of exhaustive current trends.
