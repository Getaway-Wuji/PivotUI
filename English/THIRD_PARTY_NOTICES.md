## Included changes and resource boundaries

- **Product reference research:** the internally authored `design-reference-research` module contains a lightweight 84-record source catalog and eight adapted case cards derived from [VoltAgent/awesome-design-md @ fcc70284932276d085f01ef9f83edde90b1258cb](https://github.com/VoltAgent/awesome-design-md/tree/fcc70284932276d085f01ef9f83edde90b1258cb). The original VoltAgent [MIT notice](design-research/design-reference-research/LICENSE) and [provenance](design-research/design-reference-research/UPSTREAM.md) travel with the package. Authored selection instructions and localized analysis are distinguished from upstream data; this is not a fifteenth external skill package. Full source dumps, brand assets and font binaries are excluded. The source license does not grant ownership of the brands' visual identities or rights to unrelated assets.

- **Taste:** the upstream entry, scripts, and assets are retained. Added distribution provenance and license documents are listed in [UPSTREAM.md](page-design/taste-skill/UPSTREAM.md). Photos and icons can have licenses distinct from the root MIT; consult the package's [third-party asset notices](page-design/taste-skill/THIRD_PARTY_NOTICES.md), included license texts, and source manifests for their specific obligations. Do not infer permission for an asset solely from the repository license.
- **Classics, imagegen, and historical redesign:** upstream package files and invocation metadata are retained. Each extracted package adds the applicable original root `LICENSE` and a provenance record. Legacy redesign is pinned to the historical full implementation, not a current removed path. The seven classics retain their opt-in settings; downloading them does not authorize automatic execution.
- **UI/UX Pro Max:** the complete selected package, local datasets, scripts, references, and bundled tests are included, with the original root MIT notice. Only `SKILL.md` command-path documentation is adapted so a moved or renamed package can locate its own search script; its Python code and datasets are unchanged. See [UPSTREAM.md](design-research/ui-ux-pro-max/UPSTREAM.md). The unrelated `ui-styling` package, repository CLI, and font binaries are excluded. Included font-license metadata, icon metadata, and dataset provenance remain intact. A later font or asset download is governed by that asset's license.

The English and Chinese editions use identical external-package bytes, including the stated additions and UI/UX portability adaptation. Internal instructions and this edition-level notice are maintained separately in each language.

## Runtime and verification

Source import, license preservation, and byte checks do not establish that all external workflows have run. Image-generation tools, Google Stitch, browsers, and target-project dependencies remain subject to the actual entry and available environment. Local UI/UX read-only research was checked from a renamed package and an unrelated working directory without persisting product files. Full downstream interface execution and every upstream maintenance test are outside that check.
