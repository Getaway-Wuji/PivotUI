# Dashboard 可选交互与导航适配

本文件用于选定信息结构后判断是否需要交互增强。它是对参考的综合补充，不声称截图中的动画、键盘操作或状态管理已经实现。

来源：S01–S13 导航与动效、S20–S25 玻璃交互、S32–S37 导航与内容切换，编号含义见 [来源摘要](reference-index.md)。下列条件和行为规格可独立使用，无需读取原图或逐图笔记。

已有产品先继承框架、导航组件、路由和动效偏好。下列导航仅是条件适配；Dashboard 模块不据此重做全站框架。没有相关需求时保留稳定、清晰的默认交互，不把所有效果一起加入。

## 1. 先明确控件改变什么

| 控件语义 | 改变范围 | 必须同步 | 参考 |
| --- | --- | --- | --- |
| 页面导航 | 进入另一个页面／视图 | 路由、页面标题、主体内容、当前位置 | S32、S37 |
| 实体切换 | 在门店、仓库、大棚等同类对象之间切换 | 实体名称和全部归属该实体的指标、趋势、任务、明细 | S33 |
| 时间／维度筛选 | 改变数据范围或观察角度 | 受影响模块、范围标签、比较周期、单位和导出范围 | S01、S04、S18 |
| 模块内标签 | 切换同一模块的视图／内容 | 当前标签、对应面板和上下文说明 | S02、S06 |
| 快捷动作 | 新建、记录、导出等具体操作 | 进行中、结果反馈及相关数据 | S06 |
| 视觉演示控件 | 只展示样式或转场 | 明确演示用途，不冒充真实导航 | S36 原提示词 |

S36 的原提示词允许“只更新选中态、主体保持原样”，只能用于菜单视觉演示。正式产品点击 Shoots 不能继续把 Dashboard 主体标成 Shoots。真实实体切换也不能只更新一张产量卡却遗留上一实体的环境和待办。

当前项、悬停和键盘焦点是不同状态：当前项表示用户所处位置，焦点表示下一次键盘操作的目标。一个状态不能覆盖另一个状态的可辨识性。

## 2. 导航方案的条件选择

| 方案 | 使用条件 | 不使用／改用其他方案的条件 | 必要适配 | 参考 |
| --- | --- | --- | --- | --- |
| 图文侧栏 | 入口含义需学习；名称比省宽更重要；层级较多 | 极窄工作区且入口少、用户熟练 | 可收起；保留分组和清晰当前项 | S32 |
| 顶部胶囊／文字菜单 | 少量稳定的一级入口，横向空间充足 | 长标签、多级导航或入口持续增长 | 窄屏可滚动／收纳，避免挤成无法辨认的标签 | S36 |
| 透明顶栏 | 首屏背景可控、入口少；品牌画面需要连续 | 明暗不断变化的照片使文字不清；复杂导航 | 必要时增加稳定底色；选中和焦点不能仅靠透明度 | S01 |
| 当前项展开文字 | 熟练用户、图标易辨、入口数量可控 | 大量陌生图标或展开后布局持续跳动 | 预留导航整体宽度；非当前图标也有名称 | S02 |
| 图标轨＋大标题 | 少页面工具；主体需更多宽度 | 低频陌生功能或复杂分级入口 | 页面标题与内容同步；范围选择靠近标题 | S04、S35 |
| 图标轨＋提示 | 高频熟练工作；节约横向空间有实际价值 | 触屏无法识别图标；关键入口必须常显文字 | 悬停与聚焦均有名称；触屏提供可展开标签 | S05、S34 |
| 右侧竖轨 | 明确需要完整工作画布且用户接受右侧导航 | 已有左侧框架；切换位置增加学习成本 | 新建与导航分组；保留内容真实可用宽度 | S03 |
| 同类实体标签 | 少量门店／仓库／大棚，频繁横向切换 | 对象多、名称长或需跨组织查找 | 改搜索选择器／分组列表；统一更新实体数据 | S33 |
| 底部 Dock | 少量易识别入口，轻量个人工作台 | 多级企业后台、密集表格、文字菜单必须常显 | 预留底部空间；焦点可见；当前项有明确名称 | S24 |
| 快捷动作列 | 少量高频动作确实缩短操作路径 | 动作罕用、语义不清、与导航混淆 | 标明动作名称；处理进行中与失败；窄屏可收纳 | S06 |

右轨、Dock 或图标轨只改变空间分配，不会创造额外屏幕宽度。选择时同时计算主体可读宽度、导航识别成本、触控目标和浮层覆盖。

## 3. 轻量状态反馈

### 滑动高亮与液态胶囊

- 来源：S11 的滑动高亮、S20 的沿运动方向拉伸与回弹。
- 用于说明当前项从哪里切到哪里；先保证最终选中位置清楚，再决定是否增加滑动或轻微弹性。
- 只移动背景高亮层，不挤动菜单文字、改变点击目标或让整页重新排版。
- 快速连续选择时允许中断并转向最新目标；不要排队播放过时动画。
- 焦点环独立存在，不能把滑到新位置的高亮当成焦点转移的替代。
- 减少动态效果时直接切换或轻淡入；动画结束不是路由或数据更新的前置条件。

### 数据进入与更新

- 来源：S08；从0计数、顺序绘线属于原提示词的展示效果，不是业务必需。
- 低频概览初次进入可轻量呈现；实时监控、金额核对、精确比较直接给出真实数值，避免中间数值被误读。
- 数据未返回时显示加载态；缺失值、零值、无权限和失败各自明确，不能用动画遮掩数据状态。
- 保留旧数据刷新时标明正在更新及数据时间；刷新失败可保留旧数据并标明过期，不静默当作新数据。
- 实体或时间范围变化时，先明确目标范围，再给加载状态；旧请求晚返回不得覆盖新范围的结果。
- 周期刷新保持当前筛选、滚动、展开、选中项和读图位置；不要每次重新播放全部入场动画。
- 关键异常及时可见；普通自动更新不抢夺键盘焦点。需要通知时提供简洁状态提示，避免逐个数字反复播报。
- 比较型图表尽量保持可解释的坐标范围；确需改变标尺时给出轴信息，避免仅由缩放造成“趋势突变”。

## 4. 概览到详情

### 图表、对象与明细联动

- 点击异常、柱形或对象时，先确定是高亮解释、筛选当前明细还是进入详情；控件反馈与结果一致。
- 以库存为例，选择“缺货”后明细显示对应缺货对象，并标明生效条件；选择具体商品时地图/摘要/详情同步到该对象，未参与联动的区域明确保持何种范围。
- 选中项、数量与筛选标签可见，提供清除和返回；多项选择说明组合方式，避免不可见条件越积越多。
- 无匹配明细、权限不足或详情失败时保留概览上下文。打开新详情不重复触发另一项筛选，返回后恢复原选择与位置。

### 卡片展开／原位放大

- 来源：S12 的任务面板展开、S22 的主视图与底部缩略条。
- 用于查看某一指标的趋势明细或有限任务集合，同时保留与原概览的关系。
- 详情应增加真实内容、解释或操作，不能仅放大原卡片；当用户需要同时比较两个模块时，采用并列、侧栏或独立比较视图。
- 先确定是文档流中的展开、侧边详情、模态浮层还是独立页面，再实现相应行为；避免混合模式造成滚动与焦点混乱。
- 打开时保留触发模块、实体、周期、筛选和滚动上下文；关闭后恢复到相同模块及其合理位置。
- 模态提供可见关闭、Esc、内部焦点范围和关闭后的焦点返回；内联展开使用明确展开／收起状态，不无故锁住整页。
- 隐藏的原模块不再误接收点击或键盘焦点；底部缩略入口附可读名称和当前项状态，不能只靠微缩图识别。
- S12 的“每行4张”仅是桌面参考构图；列数由内容最小宽度决定，窄屏可转为单页详情和返回按钮。
- 减少动态效果时直接出现详情并保持逻辑上下文，不能因没有动画而丢失返回行为。

### 3D翻面

- 来源：S10。只在明确偏好的品牌体验、低风险卡片或演示中考虑，不作为详情的通用入口。
- 需要并排比较、频繁读图、实时告警时优先展开或侧栏。关键指标和告警不能藏在背面。
- 用显式按钮表示“查看详情／返回概览”；卡片内部已有按钮、图表交互或链接时，不把整卡单击强行绑定翻面。
- 前后面同时存在时只让当前面可交互、可聚焦；触屏与键盘可完成切换。减少动态效果时直接切换内容。

## 5. 个性化布局与演示性收纳

### 拖拽重排

- 来源：S09。适用于长期使用、不同角色确实需要不同模块顺序的工作台。
- 先提供合理默认布局；没有个性化需求时保留固定结构，减少维护与学习成本。
- 用“编辑布局”状态和拖动把手，区分拖拽、图表刷选、文本选择、滚动和卡片按钮操作。
- 显示合法落点、占位及受影响模块；遵守卡片最小可读尺寸。跨行跨列不是无限自由覆盖。
- 提供键盘重排或上移／下移等替代，结果以可读方式反馈；不要求用户通过拖动才能完成任务。
- 完成后保存个人布局，说明保存结果；支持取消／撤销和恢复默认。保存失败时不显示“已保存”。
- 窄屏使用独立的阅读顺序或合理转换，避免把桌面三列坐标原封不动挤到单列；保留用户能理解的模块顺序。

### 一键聚合

- 来源：S13。此处“聚合”是卡片向中心收拢，不是对业务数值执行汇总。
- 仅用于用户明确要求的演示或自选收纳模式；不作为经营、告警、任务执行的默认状态。
- 收拢态仍有明确恢复动作和当前模式说明；关键告警入口保持可用。恢复后保留原布局、筛选、模块状态与焦点上下文。
- 若收拢会隐藏当前任务所需信息，则不采用。减少动态效果时可直接切换为简洁列表／折叠状态。

## 6. 命令面板

来源：S23。参考截图没有打开命令面板，搜索弹层、结果和键盘状态均需实际补充设计。

- 适合熟练用户频繁跨模块跳转，作为既有导航的补充。Dashboard 提出接入需求，由框架承担全局入口和路由一致性。
- 提供可点击入口；按宿主环境选择可用的 ⌘K／Ctrl+K，并处理已有快捷键冲突。
- 打开后聚焦搜索框；背景若是模态状态则不可被意外操作。显示结果名称、类型和当前位置，不只提供孤立图标。
- 输入实时过滤，显示无匹配结果；上下键移动当前结果、Enter 执行、Esc 关闭。快捷键不拦截输入法正常组合输入。
- 关闭后将焦点返回原入口／触发前位置；执行导航后把焦点放到新视图的合理起点，避免仍停在已卸载搜索框。
- 页面跳转、实体搜索和直接执行的命令在分组与文案上区分。新增命令执行能力属于新功能，不能从菜单过滤自动推导。
- 筛选结果按实际权限和范围生成；搜索不到与没有访问权限的反馈按产品约定处理。
- 玻璃与背景模糊是可选材质；无论材质如何，结果对比、当前选择和键盘焦点始终清晰。

## 7. 跟随光、悬浮倾斜与 Dock 放大

- 来源：S21 的跟随光／轻倾斜、S24 的 Dock 邻近放大；均属于可选表现层。
- 只用于少量展示卡或用户明确偏好的品牌细节；不倾斜密集表格、精确读图坐标或正在输入的内容。
- 跟随光限制在装饰层，不截获点击，不改变文本布局，不承担业务状态含义。未触发效果时信息和功能仍完整。
- S21 的“不超过4度”是该原提示词的上限，不是全局默认。可以只保留边界提亮而去除倾斜。
- Dock 放大不改变稳定点击目标或遮住相邻内容；底部预留区域应覆盖其最大占用。图标聚焦时也显示名称。
- 触屏默认稳定呈现，不模拟鼠标悬停；键盘使用普通焦点与文字反馈。减少动态效果时禁用跟随位移、倾斜及邻近放大。
- 玻璃表面和动态光照影响文字可读性时，增实底或移除光效；品牌表现不优先于工作内容。

## 8. 交付与验证

只为实际选中的模式验收；记录“参考所示”“本次补充”和“实际已验证”的边界。

| 检查 | 可观察通过条件 |
| --- | --- |
| 路由／实体／筛选一致 | 选中态、标题、数据范围、任务和导出对应同一上下文 |
| 键盘与触屏 | 必需操作不依赖悬停或拖拽；焦点明确；触屏能识别入口 |
| 展开与关闭 | 能清楚进入、退出、返回原位置；隐藏内容不会误获焦点 |
| 数据更新 | 快速切换没有旧数据覆盖；刷新不丢状态；失败和过期可辨 |
| 重排 | 合法落点、保存、失败反馈、恢复默认及替代操作可用 |
| 动效偏好 | 减少动态后功能和当前状态完整，操作不会等待动画完成 |
| 内容边界 | Dock、侧栏、浮层不遮住当前操作；长标签与窄屏仍可读 |
| 静态设计交付 | 未实现交互明确标注行为规格，不声称已测点击、切换或动画 |

向后续页面框架模块传递选定方案、适用条件与一致性要求；向数据列表／详情模块传递筛选上下文和进入／返回行为。保留模块分工，避免同一产品出现各自独立的导航和状态规则。
