# Retro Web / 复古互联网

来源：用户提供的参考图板 02，原标签 **Retro Web / 复古互联网**。维度：历史界面借鉴与怀旧插画。这是候选参考，不是产品默认风格。

## 观察到的证据

示例借用浏览器窗口框架、灰色斜面面板、蓝色下划线链接、小型像素插画和桌面式外框。这些是对旧界面的视觉借鉴，截图不能证明真正的窗口管理、浏览器行为或键盘约定。

## 建议采用方式

可考虑用于怀旧作品集、文化项目、游戏社区或有意采用主题的活动页。选择一组协调且可识别的约定，不混杂无关年代的元素。视觉处理之下应使用真实链接和按钮。装饰标题栏和状态细节应作为视觉内容表达，不能暗示并不存在的浏览器或系统功能。

## 组合与约束

可结合 `pixel` 提供图像语言，或结合 `minimalism` 控制内容复杂度。不要重现过时的交互限制：保留可用的触控目标、现代键盘操作、清晰焦点与有意义的导航。密集工作工具通常需要比重叠窗口模拟桌面更安静的处理。小型点阵文字不宜承担长说明。

## 资产、成本与降级

CSS 框架实现较轻，完整桌面仿真属于另一项更大的范围。除非任务确实要求窗口行为，否则优先使用静态装饰外框。窄屏可降级为堆叠面板与普通导航，保留少量可识别的复古特征。
