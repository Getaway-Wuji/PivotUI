# 适配区域，同时保留任务能力

只读取相关行。以下是补充设计方法，用户提供的图片没有展示这些产品状态。与页面负责人共同决定每个区域的实际优先级。

| 区域／变化条件 | 保留 | 重排方式与操作延续 |
| --- | --- | --- |
| 导航标签或操作容纳不下 | 当前所在位置、目标页面、必要的账号及任务操作 | 收纳到有明确名称的导航控件，或复用外壳已有变体。保留目标页面、当前页提示、开关状态和键盘访问。已打开的导航面板随尺寸变化转为桌面导航时，协调可见性、滚动锁定和焦点；不能把焦点留在隐藏面板中。不能仅因宽度变窄就选择 Drawer。 |
| 首屏／主体与侧栏无法支持可读内容 | 主要主张或任务、主要操作、相关辅助信息 | 按有意义的源顺序堆叠。将辅助材料移到相关主体段落之后。仅在不损害意义时裁切图片；有响应式图片源时使用。没有必须占满视口高度的首屏或通用栏宽比例。 |
| 控件行、筛选或表单过于拥挤 | 标签、当前值、校验信息、提交与取消路径 | 将分组换行或堆叠；让长标签可容纳，而不是删除名称。筛选可移到面板，同时保留当前筛选反馈和清楚的应用／重置流程。变化前后保留草稿值和校验信息。全宽按钮是特定任务的变体，不是所有窄布局的规则。 |
| 比较表格超出可用空间 | 行身份、列含义、比较字段、排序与筛选状态、单行及批量操作 | 需要跨列比较时，保留语义化表格并提供限定的横向滚动区域。可使用优先列加有名称的详情展开入口，前提是被收纳字段仍然可达。卡片适合逐条记录处理，不是自动的移动端转换方案。明确选择状态、全部记录与当前页范围、合计、分页及批量操作反馈。 |
| 图表标签、图形标记或图例争夺空间 | 单位、时间范围、系列身份、必要比较、数值访问 | 先调整图表排列、标签位置或刻度密度，再考虑缩小全部文字。被移除的刻度值和数据仍可通过无障碍摘要／表格或详情控件访问。若改变聚合方式，应说明变化，并保留任务需要的原始粒度访问。尺寸变化时重新测量图表容器。触屏和键盘用户需要访问仅悬停显示的数值及图例控件。 |
| Modal 超出可用宽度或高度 | 用途与标题、已输入数据、错误、关闭／取消及主要操作 | 使用适合的宽度和有边界的内容滚动。只有符合 Modal 的任务和已有交互约定时，才可采用全屏或 sheet 呈现；保留其适用条件和确认规则。低高度及键盘打开时仍应能到达操作，并保留对话框语义和焦点进入／约束／返回。宽度变化不能成为改变破坏性操作行为的理由。 |
| 保留上下文的编辑 Drawer 超出可用宽度或高度 | 编辑上下文、草稿、错误、保存／取消及返回路径 | 调整宽度和有边界的内容滚动，同时保留 Drawer 的适用条件和模态约定。不能转换为全屏 Drawer，也不能用 Drawer 承载简单表单。任务仍无法容纳时，与页面负责人协调独立编辑页或行内区域，保留草稿、进行中操作的结果追踪，以及合理的返回／焦点路径。 |
| sticky／fixed 页头、侧栏或底部操作遮挡内容 | 上下文、操作访问、可见的焦点项 | 计入实际占用空间和安全区域。固定定位时预留内容空间，高度不足时解除粘滞。避免多个相互争夺滚动的区域。检查浮层下的锚点目标、最后几行、展开的错误及表单最后的操作。 |
| 长文本、URL、代码或宽媒体越界 | 完整含义、标识符、复制与打开操作 | 普通文字换行；URL 允许合理断行。代码或本质二维的内容使用限定区域滚动。截断内容必须有可发现的方式，让键盘及触屏用户读取完整值；仅有 `title` 属性不够。 |

表格和图表不能使外围页面整体免于重排。局部滚动区域之外的工具栏、标题、说明和分页仍应可用。粘滞身份列必须给其他字段留下足够查看空间；如果占掉了有效视口，应禁用它。

区分业务优先级和装饰优先级。低对比外观不代表字段可以删去。必要时可隐藏重复装饰，但任何移出即时视野的信息都要记录访问路径。不要把视觉整洁的截图等同于完整工作流程。

复用已有组件约定和行为。需要新的紧凑、堆叠或收纳展开变体时，将触发条件、语义、状态延续和受影响调用方交给组件负责人。由一名明确的实现者整合结果。
