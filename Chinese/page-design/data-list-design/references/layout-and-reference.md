# 布局与参考

## 来源与解释

2026-11-14，制作者收到用户指定的 Ant Design Pro 标准 Table 列表参考，以及对筛选区、批量工具栏、列配置、分页和详情返回行为的描述。结构方向采用该描述。官方参考地址为 [Ant Design Pro 列表](https://preview.pro.ant.design/list/table-list/)和 [ProTable 文档](https://procomponents.ant.design/en-US/components/table/)。

制作时的网页抓取没有返回可读页面内容；不声称完成了上游渲染检查、源码核对或特定版本的运行测试。详情返回要求来自用户。下文的选择快照、失败恢复、键盘处理及窄屏布局属于补充设计方法。没有从图片测量或估计像素尺寸。使用 API 前应核查目标项目已安装的库和实际文档；本技能不要求使用 Ant Design，也不再分发其代码。

## 围绕工作编排

沿用页面标题区，依次安排查询区、结果工具栏、表格和分页。查询区与表格对齐到相同内容边缘。将工作空间留给表格；只有概览卡片能回答与本列表有关的具体问题时才添加。产品现有应用框架决定导航及内容起始位置。

保持常用筛选可见。将低频条件放入名称清晰的展开区域，提示隐藏条件是否生效，折叠时保留其值。昂贵查询或多字段组合宜采用明确的“应用”；成本较低且反馈清晰的搜索可以即时筛选。用户应能区分刚输入的内容与当前结果对应的条件。

结果工具栏放置列表名称、数量和适用操作。主要的新建／导入操作与视图、列配置、刷新分组。表格上方的选择相关操作旁展示选中数量和范围。破坏性操作应可识别，但不与日常主要任务争夺强调。只对选中集合有意义的操作，不应在每一行重复。

## 密度与阅读顺序

按照用户要做的决策选择列：识别信息在前，常用比较字段与状态随后，低频元信息靠后。上下文操作位置保持一致。在识别单元格提供真实的详情链接；可选的整行点击仅作增强，不得拦截复选框、链接或文字选择。

复用产品的密度变体。选择紧凑模式前，用真实长度的双行名称、缺失值和状态标签评估行高。主要标识的强调程度高于次要 ID 或时间戳；使用既有文字角色，而非为每个单元格单独指定字号。可比较的数值和单位保持一致对齐。区分零值、缺失值和加载中的值。

长标识需要换行，或提供明确、可访问的完整值入口；关键信息不能依赖悬停 Tooltip。当第二行有助于保持逐行比较时可使用；冗长说明可放在展开区或详情。不要通过隐藏操作标签或整体缩小文字来塞入更多列。

## 列与视图

列配置控制展示，不控制访问授权。使用有名称的复选框，并提供恢复约定默认值的操作；保留识别信息及详情／操作入口。隐藏、排序或固定等能力只按组件和任务需要提供。定义设置的持久化范围，在字段结构或权限变化时处理失效列。不能仅因敏感字段被视觉隐藏，就将其下发给客户端。

保存视图是范围明确的命名预设，例如已应用筛选、排序、密度和列。选择状态及进行中的任务不进入保存视图。提示视图是否存在未保存修改。明确保存仅改变当前用户的视图，还是修改共享视图；共享须具备实际能力和授权。简单列表可以不提供视图管理。

## 窄空间

重排查询控件和工具栏分组，同时让范围标签与相应操作保持关联。以横向比较为主的表格，可保留有名称的局部水平滚动区域；以单个对象为主的工作，可采用可访问的行展开或卡片。每个必要字段都能连同标签到达，每项操作都可用键盘与触屏完成。隐藏列需有列选择器或详情入口。分别验证页面滚动与局部滚动；吸附区域不得遮住焦点、分页或操作结果。视口变窄不改变选择和查询语义。
