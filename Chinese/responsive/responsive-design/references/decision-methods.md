# 从内容出发选择变化

规划布局切换或选择 CSS 机制时读取。先明确任务，再选择能保留任务能力的机制；用户提供的八张教学图片是技术线索，不是一组只能互选其一的方案。

## 实用的决策记录

| 字段 | 需要明确 |
| --- | --- |
| 条件 | 哪些内容失效，发生在实际测得的什么视口／容器空间或输入条件下？ |
| 保留 | 完成此任务必需的信息、关系和操作 |
| 重排 | 换行、堆叠、减少列数、移动、收纳后展开或允许限定区域滚动 |
| 继续 | 下一步操作在哪里，用户如何发现它，哪些状态需要延续 |
| 证据 | 参考中观察到的状态、实测行为或补充设计；仍需完成的验证 |

例如：筛选栏再也容纳不下可读标签和可用控件时，保持搜索和当前筛选反馈可见，让控件换行或提供有明确名称的筛选面板，并在面板开关时保留值和结果。这是建议的方法，不是从参考图片中观察到的行为。

## 选择机制

| 机制 | 适合用途 | 它不会替你决定的事项 |
| --- | --- | --- |
| 百分比／弹性宽度 | 分配可用空间；有边界的页面留白 | 最大可读行长、子项最小可用尺寸，以及什么内容应改为堆叠 |
| 带换行或方向切换的 Flex | 一行或一列控件、导航项、元数据 | 不会自动换行；需检查内容固有最小尺寸和操作标签 |
| Grid | 对齐的行列、卡片集合、主体与详情区域 | 固定列数需要内容适配策略；Grid 并非在所有情况下都优于 Flex |
| 视口媒体查询 | 可用空间随视口变化的页面外壳、导航或区域 | 宽视口里也可能存在窄组件 |
| 容器尺寸查询 | 放置在不同位置的可复用卡片、工具栏或面板 | 需要合适的祖先容器和支持它的浏览器／运行时；查询作用于其后代 |
| `rem`／`em` | 随字体变化的尺寸与协调的组件比例 | 不会自动使布局响应式；缩小根字号会连同可用性一起缩小 |
| 视口单位／有上下界的流动值 | 确实与视口尺寸相关的空间 | 纯 `vw` 文字和固定视口高度的内容可能无法适应缩放、长文案或浏览器界面 |
| 框架栅格／工具类 | 在现有技术栈中表达已选定的布局 | 类名、断点和插件支持随框架及版本变化 |
| `rpx` 等平台单位 | 明确支持这些单位的运行时 | 不是标准浏览器 CSS；实现前检查该平台的当前规则 |

当内容自然换行或流动尺寸能直接解决问题时，优先使用它们，不必添加切换。不同方法解决不同维度时可以组合。CSS 已能清楚表达的行为，不额外引入 JavaScript 尺寸监听；仅在图表 resize API 等确有需要的情况使用运行时测量。

## 确定切换位置

先使用项目约定，包括已有容器与组件变体。没有既定阈值时，用真实的长标签、多语言、数据量和缩放状态调整尺寸。找到当前排列失效的位置，确定原因，再在失效前切换。记录依据与作用范围。不要将教学图片中的 600/1024 或 Tailwind 默认值当成设备要求。

无前缀的窄布局配合最小宽度增强，通常能简化新建任务；局部修复应保留已经合理的现有方法。避免一个范围止于 600px、下一个始于 601px 这样的媒体查询间隙：视口宽度可能是小数。使用基础样式加最小宽度覆盖，或项目支持的互补范围语法。

估算列数时使用实际可用内容宽度，并计入页面留白和侧栏。大屏限制阅读行长和媒体宽度，无需拉伸每个区域填满空间。标题可以在已采用的字号体系中变化，但重要文字放大后仍须可读。保留一套有意义的内容顺序；CSS `order`、Grid 定位，以及重复的桌面／移动控件，不得产生误导性的焦点顺序或重复的活动表单 ID。

## 小型实现模式

以下声明用于说明机制，不是产品 token。复用项目实际值和选择器；采用前检查浏览器支持。

```css
/* Allow a nested layout item to shrink; wrap only text that may break. */
.content-slot { min-inline-size: 0; }
.long-reference { overflow-wrap: anywhere; }
.media { max-inline-size: 100%; block-size: auto; }

/* Illustrative 16rem card minimum and 1rem gap, not library defaults. */
.cards {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(min(100%, 16rem), 1fr));
  gap: 1rem;
}
```

如果某条弹性轨道应允许缩到内容自动最小尺寸以下，使用 `minmax(0, 1fr)`，并为内容明确换行或滚动策略。仅把最小值设为零无法修复不可断行的子项。对于比较任务较重的图表和表格，选择有意义的最小尺寸与局部滚动替代方案，不要挤压到无法阅读。
