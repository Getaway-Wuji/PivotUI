# Maximalism / 极繁主义

来源：用户提供的参考图板 04，原标签 **Maximalism / 极繁主义**。维度：丰富的表现性视觉与分层构图。这是候选参考，不是产品默认风格。

## 观察到的证据

示例结合饱和色彩、多种纹理、贴纸、雕塑与照片片段，以及大号展示文字。元素众多，主标题仍是焦点。密集截图不能证明有效的信息密度或交互图层。

## 建议采用方式

可考虑用于文化活动、音乐、创意团体，以及丰富表达能服务明确信息的品牌区域。选择主导焦点、协调的图像体系和有意图的次级元素层级。装饰密度应与用户必须处理的信息量分开考虑。

## 组合与约束

可结合 `collage` 构建图像，或结合 `editorial` 保持内容顺序有条理。给操作和核心文案预留安静区域。不要将所有装饰手法延伸到表单、表格与错误信息。窄屏减少或重排装饰层，同时保留有意义的内容和顺序。重叠不能遮挡焦点或触控目标。

## 资产、成本与降级

多组协调资产、合成和响应式美术安排需要较多工作。使用现有的相关图片，不用无关物件填满页面。资产或屏幕空间有限时，将构图缩减到少量有力图层，保留相同的焦点层级。
