# 验证与交接

按交付范围选择检查。设计规格可以给出可执行验收计划，但不能声称浏览器验证通过。对于实现，使用真实感的合成记录演练有意义的流程，并记录视口、浏览器、操作和结果。制作期演示与原始证据留在分发技能之外。

| 检查 | 操作与可观察结果 |
| --- | --- |
| 长内容 | 中外文混排长名称／ID、缺失值、大数值；完整值与操作仍可到达且不重叠 |
| 查询状态 | 应用多条件筛选、重置、无匹配、加载失败／无权限；状态正确、输入保留且有恢复路径 |
| 列／视图 | 隐藏／重置列、切换相关视图；识别／详情路径保留，权限有效，持久化符合约定 |
| 选择范围 | 选择本页、翻页、支持时明确选择全部匹配、排除一条、改变筛选；标签与受影响 ID 一致 |
| 部分失败 | 提交混合结果任务；原因持续可见、计数正确，不重新处理成功项，仅重试可重试失败项 |
| 详情返回 | 从已筛选的后续页及已知滚动／焦点锚点离开；分别用界面和浏览器“后退”返回；恢复查询、页码、条数、排序和有用位置 |
| 数据变化 | 删除来源记录、使其失去访问权限，或清空最后一页；提供有效回退和清晰说明，无虚假选择 |
| 键盘 | 完成筛选、选择、设置、确认和详情返回；焦点可见且顺序合理，真正模态之外没有焦点陷阱，控件移除后焦点仍有合理去处 |
| 实际对比度 | 检查标签、值、链接、状态和选中／错误状态的计算前景色与有效背景色；采用 WCAG AA 文字目标（普通文字 4.5:1，符合大字条件的文字 3:1），记录实测颜色对 |
| 窄屏字段 | 在相关小宽度及缩放下，到达每个必要字段、标签和操作；局部滚动／展开有效，无整页裁切 |
| 导出 | 验证文件／任务内容与所声明范围、字段、权限一致；不将合成完成状态表述为真实远程任务 |

对比度标准参考：[WCAG 最低对比度](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)。仅计算检查不能证明全部无障碍要求：还应目视检查重叠、焦点可见性、禁用／状态上下文和实际渲染。未测试的辅助技术、实体设备、后端行为或性能应明确标记未测。

交接时说明列表区域负责人、继承的 Token／组件来源、查询／选择／任务／返回约定、补充决策、改动文件和实际结果。解释共享组件或 Token 提议，不悄然扩大修改范围。本制作工作区的模块记录为 `design-system/modules/data-list-design.md`；其他项目采用自己的记录约定。该工作区路径不是运行依赖。
