# 可携带规范

来源版本：共享界面设计基础规范 0.2；内源／外源设计技能联动协议 0.4.1；interaction-design 1.1.0 浮层约定（2026-11-14）。本文件为供独立使用的列表相关摘编。当前明确用户指令和目标项目约定优先。不需要原始制作文件或安装其他技能。

- 从用户任务和参考推导信息优先级与密度。沿用产品应用框架、控件及唯一权威 Token 来源。样例的配色、字体、圆角或间距不成为库默认值。
- 保持组件角色、数值格式和状态含义一致。状态除颜色外还需文字或符号。区分零值、缺失值和待加载值；适应长文本与真实数据量。
- 一个区域由一名主负责人负责，一个组件由一名实现者负责。专家补缺口，由负责人整合；已有且满足要求的行为无需重建。
- 相关控件应有清晰名称、可见焦点，并可用键盘操作。协调模态焦点进入／约束／返回与固定层级。窄屏保留必要内容和操作路径，不通过全局裁切溢出来解决问题。
- Tooltip 用于补充说明；Toast 用于轻量结果，不能用于错误；问题使用持久 Alert／行内区域。Modal 处理不可逆确认／复杂信息；Popconfirm 用于低风险就近确认。Drawer 用于保留上下文的编辑，排除简单表单和全屏任务。普通详情导航可以进入页面。
- 防止重复任务，失败后保留输入，并区分加载、空数据、无匹配、失败和无权访问。参考的观察事实、估计与补充设计分别记录。运行验证结论必须有实际执行依据。
