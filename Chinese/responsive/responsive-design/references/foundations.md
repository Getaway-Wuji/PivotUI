# 可移植共用设计基础约定 — 响应式设计

同步摘编自《界面共用设计规范》**0.2** 与《自制与外源设计 Skills 联动方案》**0.5.0**。仅在目标项目缺少自身设计规范时读取；在完整集群中运行时，以本版 `design-system/FOUNDATIONS.md` 与 `design-system/ORCHESTRATION.md` 为准。

## 核心不变量

- **任务优先的信息层级**：围绕用户需要理解、判断与完成的工作安排结构、分组、对齐和视觉强调。
- **唯一权威 Token 来源**：优先复用目标产品既有 CSS 变量、主题对象或组件库配置。不同区域差异通过命名明确的变体表达；不维护两套各自可改的主题，也不把客户品牌写回技能库默认值。
- **单负责人制**：每个页面区域由一位主负责人统筹，每个共享组件由一位负责人整合；专项模块仅在存在具体缺口时参与，而非固定全量流水线。
- **真实内容与完整状态**：兼容长文本、中英文混排与等宽数字，明确区分零值、空值与未加载状态，按需覆盖加载、空态、错误、权限、焦点与键盘可达性。
- **浮层与边界纪律**：Tooltip 仅做简短补充；Toast 仅承载轻量非错误反馈（不承载错误）；Alert 持久呈现问题；Modal 用于不可逆确认；Popconfirm 仅用于低风险局部确认；Drawer 用于保留上下文的编辑且不承载全屏任务。`gpt-taste` 仅用于公开营销，禁止用于 Dashboard 或业务工具。
- **响应式与滚动纪律**：根据可用宽度、高度与输入方式适配内容与操作，不用全局横向裁切掩盖溢出或随意删减关键业务字段；区分框架主滚动与局部表格/面板滚动。
- **诚实验证**：明确区分文档审阅、静态脚本校验、浏览器渲染检查与真机测试，不将未执行检查报告为通过。
