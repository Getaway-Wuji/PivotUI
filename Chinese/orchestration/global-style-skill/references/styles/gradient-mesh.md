# Gradient Mesh / 渐变网格风

来源：用户提供的参考图板 06，原标签“Gradient Mesh / 渐变网格风”。维度：背景色彩与光感处理。

## 观察

大片柔和粉、蓝、紫过渡铺在首屏标题和半透明观感的功能面板之后。色域具有多个柔和中心，而非单条清晰色带。静态图像不能证明动画、着色器、真实透明度，或构图各处都具备可靠对比度。

## 建议用途与组合

氛围有助于信息表达时，可在限定的介绍或宣传区域使用类似网格渐变的背景。沿用目标产品已采纳的颜色角色，不自动引入另一套配色。柔和色域搭配清晰字体，并为重要内容提供稳定表面。可与简单分屏布局或产品预览组合；没有具体理由时，不叠加竞争纹理与多种强光效。

## 限制、资产与降级

按文字、图标、边框、控件下方的实际变化背景检查可读性；实色内容表面可能比玻璃效果更易读。渐变不承担状态或数据分类含义。静态图片或适量 CSS 分层即可实现；连续动画和 Canvas 效果增加了参考并未要求的工作。若对比度、性能或资产约束不适合复杂色域，降为柔和简单渐变或实色表面。
