# Split Screen / 分屏构成风

来源：用户提供的参考图板 08，原标签“Split Screen / 分屏构成风”。维度：布局构成。

## 观察

首屏沿纵向明显分区，一侧为浅色文字区，另一侧为蓝调建筑摄影，上方设置简单导航。两侧视觉职责不同。截图只展示一种宽屏安排，不能确定必须等宽、占满视口高度或采用何种窄屏方案。

## 建议用途与组合

两个内容角色适合相邻呈现时可考虑分屏，例如说明与证据、文字与产品图，或真正可比较的两个选项。根据内容重要性决定比例。该布局可组合黑白摄影、克制品牌方向、几何装饰或其他处理，本身不构成独立配色或组件体系。页面负责人决定结构和阅读顺序，响应式负责人按可用空间调整安排。

## 限制、资产与降级

不将无关内容强行配成对称两栏，也不为保留分界压缩文字。窄屏可堆叠或重组区域，同时保持核心信息与操作顺序合理。摄影需要合适裁切，但分屏也可容纳有用文字或产品预览。布局本身成本较低，脆弱固定高度会增加不必要工作。内容或空间需要时，降为不等宽列或清晰单列顺序。
