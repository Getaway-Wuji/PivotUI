# Collage / 拼贴风

来源：用户提供的参考图板 04，原标签 **Collage / 拼贴风**。维度：分层图像构成与有触感的编辑式纹理。这是候选参考，不是产品默认风格。

## 观察到的证据

示例在奶油色背景上组合照片剪片、撕纸边缘、胶带式细节、手写元素和重叠图层。其配色与构图比相邻的 Maximalism 示例更安静。图片没有证明可移动碎片、物理模拟或可交互手写内容。

## 建议采用方式

可考虑用于个人故事、旅行、文化、创意作品集和局部编辑内容。先建立阅读顺序，再通过图层连接或强调相关素材。区分有意义的图注与装饰涂写。标题和重要文案应保持为可读的网页原生文字，不要嵌入合成为单张图片的拼贴中。

## 组合与约束

可结合 `editorial` 叙事、`hand-drawn` 提供有限标注，或结合 `minimalism` 为构图留出空白。拼贴不要求页面密集。避免遮住操作区域、将相关文字散落在相距很远的碎片上，或让撕纸边缘看起来像内容被意外裁切。普通业务控件仍需清楚边界。

## 资产、成本与降级

抠图、一致纹理和响应式重排会增加资产工作，静态构图通常已经足够。小屏无法清楚呈现图层时，可按明确顺序展示相同图片和图注，只保留少量有触感的装饰。
