## Publication scope / 发布范围

Release packages retain the resources that the included skills reference, together with original upstream examples and their notices. Authoring-workspace demos, local test outputs, intermediate research images, personal launch settings, caches and virtual environments are excluded. Names such as `assets/demo` inside an upstream package can identify a reusable resource library; they are distinct from this project's local experiments.

发布包保留随包 Skill 引用的资源、上游原版示例及其声明。编写工作区里的本地演示、测试输出、中间研究图片、个人启动设置、缓存和虚拟环境不纳入发布。上游包中的 `assets/demo` 等目录可能承载被正式引用的复用资源，与本项目本地实验文件有区别。

Preserving notices and checking source integrity establishes provenance; it does not certify every external service or design workflow. The package-level records describe what was imported and changed. These credits acknowledge upstream work without implying endorsement by any upstream author or referenced brand.

保留声明和核对来源完整性用于确立出处，不代表所有外部服务或设计流程均已执行认证。逐包记录说明实际导入和改动。本页致谢上游工作，不暗示上游作者或参考品牌为本项目背书。
