# 导航交互

这是 `interaction-design` 的按需子模块。继承 [根入口](../../SKILL.md) 已确定的范围、token、证据标记与可选项目规范；已获得约定时不重复加载。直接进入且缺少约定，只补读根入口的“接受范围与现有决定”。

负责导航行为，保持页面主力的信息架构、路由和布局。hover/focus 表达临时探索，current 表达真实位置，expanded 表达分组开合；不同状态可以并存，不以临时高亮替换真实路由。以下为实现建议，不是静态参考的运行结论。

## 先辨别导航语义

| 类型 | 状态依据与输入模型 | 避免混用 |
| --- | --- | --- |
| 站点/侧边栏链接 | href 或实际路由，保留原生链接与自然 Tab 顺序 | 不因外观叫 Menu 就套命令菜单方向键模型 |
| 折叠分组 | 按钮控制 expanded，Enter/Space 开合 | 跳转链接与开合按钮职责不清；收起后仍可 Tab 到隐藏项 |
| 面包屑 | 当前页面的层级祖先路径 | 把访问历史当层级，或让每个片段都拥有“当前页”标记 |
| 同页 tabs | selected tab 与对应 panel | 将路由链接、单选表单值都套成 tab |
| 行操作/命令菜单 | 当前菜单项焦点与实际命令 | 把 hover 项当已执行命令，或把 Tab 困在非模态菜单内 |

## 侧边栏、分组与面包屑

| 触发条件 | 状态变化 | 用户反馈 | 退出或恢复 |
| --- | --- | --- | --- |
| 路由实际改变 | current 更新 | 当前页标记与内容一致，适用时链接 `aria-current="page"` | 导航失败仍显示真实所在页，不只因按下就永久改 current |
| hover/focus 另一项 | 临时强调改变 | 焦点环与当前项标记均清晰 | 移出/失焦回到真实 current；无 current 则清除临时态 |
| 展开/收起分组 | expanded 切换 | 图标及 `aria-expanded` 同步 | 关闭前若焦点位于将隐藏内容，移到合理的分组控制；隐藏项不再可聚焦 |
| 收窄侧边栏 | 视觉宽度/标签呈现变化 | 图标仍有名称，当前页仍可辨 | 焦点和当前路由保留；不能只靠 hover 才认出关键入口 |
| 激活面包屑祖先 | 进入相应层级 | 路径与页面标题同步 | 保留原生返回与链接行为；当前页片段通常无需再次跳转 |

分组标题兼有链接与开合时，提供可区分的链接和按钮，不让同一次激活同时折叠又跳转。侧边栏收纳方式交响应式能力或当前实现负责人决定；窄屏不自动意味着 Drawer，更不借局部交互重排全站导航。

面包屑使用有名称的导航区域及有序层级；链接按自然 Tab 顺序，分隔符不成为额外焦点。当前页如为链接，使用 `aria-current="page"`；若为普通文本则不强行做成按钮。依据：[APG Breadcrumb](https://www.w3.org/WAI/ARIA/apg/patterns/breadcrumb/)、[APG Disclosure](https://www.w3.org/WAI/ARIA/apg/patterns/disclosure/)。

客户端路由切换后沿用应用已有的标题、焦点和滚动管理。普通 hover、打开分组、后台数据刷新不抢主内容焦点；实际换页或返回列表时，依据任务恢复到内容入口或先前操作位置。

## 页内标签与命令菜单

| 触发条件 | 状态变化 | 用户反馈 | 退出或恢复 |
| --- | --- | --- | --- |
| tabs 内方向键移动 | 焦点 tab 变化；是否立即 selected 按策略 | 焦点与已显示 panel 可区分 | 手动激活时 Enter/Space 才切 panel；Tab 进入后续内容 |
| 激活命令菜单按钮 | collapsed → expanded，焦点进入项目 | 当前项目可辨，触发器状态同步 | Esc 关闭并回触发器；Tab 关闭后按正常顺序继续 |
| 菜单内游走/执行 | 项目焦点移动或命令执行 | 项目名称与不可用原因可理解 | 执行后按后续流程定位；触发器已消失则用稳定对象身份选择合理后备 |

tabs 沿用组件库的方向、Home/End 与焦点管理。只有面板可即时显示时才考虑焦点即激活；需要网络加载时采用明确激活，避免方向键每移一步都触发等待。隐藏 panel 不保留可聚焦子项。依据：[APG Tabs](https://www.w3.org/WAI/ARIA/apg/patterns/tabs/)。

命令菜单使用对应的方向键、Home/End 与适用的首字母导航，监听限定在组件范围。嵌套菜单 Esc 逐层退出；关闭动画期间也不能留下可 Tab 的隐藏项目。行菜单按稳定行 ID 恢复焦点，排序或过滤后不按旧索引跳到另一条记录。依据：[APG Menu Button](https://www.w3.org/WAI/ARIA/apg/patterns/menu-button/)。

导航项需要 Tooltip 或命令后需要确认/结果反馈时，读 [浮层组件](../floating-components/SKILL.md)；不要用 Tooltip 承担重要反馈，不用 Toast 显示错误。创意菜单动画的语义、Esc、焦点与减少动效缺口按 [React Bits 接入](../../references/react-bits.md) 核对，不能直接当成业务模态抽屉。

## 交付检查

- 当前页、临时悬停、焦点和分组开合可区分；路由失败不会留下虚假 current。
- 仅用键盘可访问侧边栏和面包屑；收起后隐藏项不再可聚焦，展开/收起不丢合理焦点。
- 菜单 Esc 与 Tab 各走正确退出路径；行被移除、重排或筛选后焦点仍有可靠位置。
- tabs 的激活策略与延迟匹配，页面全局键盘和滚动不被局部控件夺走；只报告实际执行过的检查。
