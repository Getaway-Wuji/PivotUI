# 可独立使用的共用约定

以下必要方法摘编自 Shared Interface Design Foundations **0.2** 和 Orchestration **0.4.1**，支持独立使用，不依赖原始仓库。明确用户要求和目标产品已有约定优先。

1. 围绕用户任务组织界面。先用位置、对齐、间距、排版与分组表达层级，再添加装饰。
2. 同级页面保持导航、内容起始线、标题和全局操作位置一致。页面内容可采用任务所需的构图。
3. 使用产品权威 Token 和已有组件约定。本包不规定通用配色、字体、圆角、密度或主题。新增共享值需要唯一维护来源和明确的使用方。
4. 每个区域和组件指定一个负责人。外壳、页面内容、行为、组件实现及响应式支持分别提供贡献，由指定负责人整合。缺少专家模块不阻断普通工作。
5. 区分 current／expanded／focus 及其他相关状态。使用有名称、可用键盘操作的控件、可见焦点和适当的焦点恢复。在可恢复的变化中保留输入与操作状态。
6. 区分页面和局部滚动；固定区域与浮层必须让内容、操作和焦点可到达。根据真实内容和可用空间适配。
7. 记录参考能确定的内容、估计与补充决定。产品专属决定保留在该产品内，不将样例品牌推广为库规则。
8. 交付实现时检查实际渲染和行为。只报告执行过的检查；静态规则审阅不证明运行时或设备兼容性。

独立包携带这些摘编，使共用基础规则可用，而无需加载无关模块。维护后续版本时，与其来源版本核对并同步。
