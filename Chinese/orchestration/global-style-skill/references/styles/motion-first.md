# Motion-first / 动效主导

来源：用户提供的参考图板 04，原标签 **Motion-first / 动效主导**。维度：具有运动感的构图与可能的体验方向。这是候选参考，不是产品默认风格。

## 观察到的证据

静态示例包含重叠倾斜面板、重复斜向文字和紫黑构图，令人联想到运动。它不能证明真实动画、时序、滚动行为、转场或响应式表现。可见构图与图板上的动效标签应作为不同类型的证据。

## 建议采用方式

在运动确实服务于具体叙事时，可考虑用于对外品牌故事或表现性作品集。应补充每个动画的目的、触发方式、稳定阅读状态、中断行为和减少动态效果替代方案。不要自行编造滚动序列，再声称来自观察。

## 组合与约束

可结合 `minimalism` 为运动留出注意力，或结合 `collage` 形成受控的分层构图。没有动效时，操作和阅读顺序仍需可靠。不要将沉浸式营销序列带入 Dashboard 或重复业务任务，后者需要的是与任务相关的反馈。避免强制滚动、延迟内容可达，以及持续与文字争夺注意的运动。

## 资产、成本与降级

动画需要独立实现，并在不同输入方式和设备上检查。先有完整静态布局，在用户偏好减少动态效果、性能有限或动画不受支持时保留它。风格选择本身不意味着选定动画库或授权调用外源 Skill。
