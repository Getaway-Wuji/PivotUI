# 验证与交接

实现或评审外壳时读取。选择与改动相关的检查，记录实际环境与结果。

## 运行时检查

| 检查 | 操作 | 通过依据 |
| --- | --- | --- |
| 位置 | 打开列表、深层详情／编辑链接，使用浏览器后退／前进 | 内容、当前导航祖先、展开路径、面包屑与标题一致；直接进入有有效返回路径 |
| 返回状态 | 筛选列表、滚动、打开记录、编辑／取消、返回 | 约定的筛选／页码／选择／滚动保留；按稳定标识或已记录的回退恢复焦点 |
| 长标签 | 长译文导航名称、页面标题、面包屑 | 标签与操作仍可到达；文字不将内容挤出所属区域 |
| 键盘 | Tab／Shift+Tab、Enter／Space 展开、进入内容 | 可见焦点按有意义的顺序移动；展开与导航区分；隐藏项不能获得焦点 |
| 收起 | 展开／收起分组及侧栏，包括焦点位于内部的情形 | 无隐藏焦点、路由丢失或不可访问的目的地；current 与 hover／focus 可区分 |
| 窄屏与短高度 | 相关宽度、转换点附近和减小的高度 | 导航可用、控件可容纳、末端条目可到达；尺寸变化保留工作并正确处理临时导航 |
| 滚动与层级 | 主内容和长侧栏分别滚动；到达首尾操作 | Header／侧栏按约定保持；无竞争的页面滚动或被遮挡焦点；局部溢出限制在所属区域 |
| 对比度 | 检查实际渲染的前景／背景组合，包括弱化、选中和悬停文字 | 记录实测比值；WCAG AA 下普通文字至少 4.5:1、大号文字至少 3:1；焦点和控件清晰可辨 |

产品无障碍目标更严格时从其要求。对比阈值依据 [WCAG 最低对比度](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)。检查实际背景，而不只看 Token 名称。

仅制作规格时，审阅决策及可执行验收条件，不将浏览器检查标为通过。区分自动化行为检查、视觉检查、真机测试和辅助技术测试。

## 交接

简短记录即可：

- 选定组合与适用条件；持续存在和路由专属的区域。
- 路由匹配、面包屑／标题／操作元数据及返回约定。
- 内容宽度／内边距、滚动归属、fixed／sticky 层级、窄屏转换。
- 复用的组件／Token 来源，以及每个区域唯一的实现负责人。
- 参考依据、估计与补充选择。
- 改动文件、实际检查、未解决问题与未运行的环境。

页面负责人使用约定的内容和操作插槽，不应重建外壳，也不应再用另一个全高页面滚动容器包住外壳主滚动区。专家模块向指定负责人交回限定范围的要求或修复。原始研究和样例证据保留在制作记录中，不进入独立技能包。
