# Dashboard / 数据看板风

来源：用户提供的参考图板 05，原标签“Dashboard / 数据看板风”。维度：业务类型与产品预览构图。

## 观察

示例是营销首屏：宣传文字旁边放置包含指标卡和图表的浅色界面预览，并非完整的业务后台。图像不能证明指标定义、图表正确性、数据状态、导航、权限或可用交互。

## 建议用途与组合

当看板预览能说明分析或业务产品的价值时，可参考此构图。优先使用用户提供的产品截图，或明确标示为示意、内容相关的样稿。搭配克制字体和简单布局，让核心信息保持易懂。实际后台仍由 Dashboard 模块负责指标优先级、数据解释、图表及内容结构；应用框架和数据列表保留各自职责。预览的外观不能代替这些方法。

## 限制、资产与降级

不得将虚构样例指标呈现为客户成果或真实业务证据。首屏小图表可以是示意，但关键主张必须在缩小的界面外有可读文字。产品截图需要准备和合适裁切。缺少可信资产或数据时，可采用明确标识的结构示意或简明产品说明。对于真实业务页面，应从实际需求决定概览或表格形式。
