## 使用

将本目录整体安装到宿主声明的技能根目录，保留入口、UI 元信息和相对引用。处理响应式任务时打开 [SKILL.md](SKILL.md)，或让现有 `design-orchestrator` 按能力发现它。包内已包含独立工作所需的共享约定。阅读和使用本方法不要求安装框架、拥有账号、访问原始研究档案或完整技能集。

独立分发归档还在该语言版本的 `mcp/skill-cluster/` 下包含现有本地技能集 MCP 源码和同语言使用指南。按照指南创建环境并安装声明的依赖。其默认发现根目录是所在语言版本目录，移动位置后仍然如此。包内不包含运行环境或个人启动配置。MCP 提供指导，由执行任务的代理实现这些指导。

## 内容与边界

本包含精简入口、UI 元信息、本使用说明及七份按需参考：决策方法、区域模式、输入与溢出、Tailwind 适配、交接与验证、可移植基础约定、来源与采用边界。示例片段用于说明机制，不是经过验证的产品模板。原始图片、详细研究、演示、验证脚本和历史档案均留在包外。

本次单模块发布不更新完整技能集的发布版本、语言基线或共享来源表。现有主控已列出此能力；使用前应发现实际入口。过时的 MCP 连接可能需要由其负责人刷新根目录配置。完整技能集的接入建议另记在作者模块记录中，分发后的技能不依赖该记录。

目标产品的 token 和具体响应式阈值保留在该产品中。后续参考应进一步明确适用条件和证据，先更新英文，再完成等义中文同步后发布模块。
