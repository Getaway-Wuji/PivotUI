## Use

Install this entire directory in the host's declared skill root, retaining its entry, UI metadata and relative references. Open [SKILL.md](SKILL.md) for a responsive task or let the existing `design-orchestrator` discover its capability. Shared conventions needed for independent work are included. No framework installation, account, original research archive or full cluster is required to read and use the method.

The standalone archive also includes the existing local skill-cluster MCP source and same-language usage guide under the edition's `mcp/skill-cluster/`. Follow that guide to create an environment and install declared requirements. Its default discovery root is the containing language edition, even after relocation. No environment or personal launch configuration is bundled. MCP supplies instructions; the task-performing agent implements them.

## Contents and limits

The package has a concise entry, UI metadata, this usage document and seven on-demand references: decision methods, region patterns, input/overflow, Tailwind adaptation, handoff/validation, portable foundations and source map. Illustrative snippets explain mechanics; they are not a tested product template. Raw images, detailed research, demonstrations, validation scripts and historical archives remain outside the package.

This single-module release does not update the full cluster's release, language baseline or shared origin tables. The existing orchestrator already lists this capability; discover the actual entry before using it. A stale MCP connection may need its root configuration refreshed by its owner. Full-cluster integration recommendations are recorded separately in the authoring module record, which is not required by the distributed skill.

Keep target-product tokens and concrete responsive thresholds in that product. Future references should refine conditions and evidence, with English-first changes and equivalent Chinese updates before a module release.
