初次审计下载了 170 个文本/许可文件，将来源 SHA-256 与字节数和固定版本 CDN 目录比对，并检查八份 DESIGN 文档。这只建立来源完整性和文档审查证据，不证明网站真实性、当前有效性、精确 CSS 实测、视觉还原、无障碍、键盘或响应式行为。其余 76 项保持 `indexed_only`，范围/标签为 `unknown`。

不要将全部上游文件当作统一有效的 YAML schema 解析：本次快照包含无 frontmatter 的文件，以及 frontmatter 无法解析的文件。目录值来自来源清单，案例语义来自文档审查，不靠盲目提取字段。

更新时固定新提交，保留原来源记录，比较改变的原文；在更新审查状态前复查相关卡片说法、排除项和原文定位。哈希变化能发现来源漂移，不能证明事实准确性。先维护 authored English，再对中文卡片、索引、指南和 UI 元信息做语义同步；原版外部文件和稳定元数据在两版中保持匹配。产品 Token 的变化属于对应产品，不属于本包。
