# 接入、跨页面复用与验证

主控交接、多个调用方或交付检查时读取。沿用项目已有记录，不要求另建 manifest 或繁琐文档流程。

## 交接约定

输入上下文应明确区域与任务、允许修改范围、页面/组件负责人、已安装技术栈/组件库、主题位置、指定参考、行为/设备约束和预期成果。提问前先在项目中定位事实。专业模块不是强制依赖；缺失时利用本 Skill 与可用方法完成普通要求。

只返回当前相关事实：

| 项目 | 有用的交接内容 |
| --- | --- |
| 组件 | 复用的导入、修改的共享文件、新增组件及当前调用方 |
| 接口约定 | Props/值类型、稳定标识、事件、组合点及请求/状态归属 |
| 变体 | 名称、使用条件、与已有选项的区别、支持组合和默认值 |
| Token | 权威来源、已有映射、新增公共值建议及理由、受影响组件/页面 |
| 分工 | 页面主力负责的业务内容、收到或自行补齐的行为规则、响应式决定、一位整合负责人 |
| 证据 | 实际执行的检查及范围、结果、局限和仍需完成的迁移 |

主控归并公共 token 变化，全局风格能力可用时由其生成/校验。没有主控时，只在项目已有权威来源中添加必要且限于该项目的值，并记录用途与调用方。不创造整个技能库通用的配色。已有完整主题的局部修复无需新建 token 流程。

现有浮层专业模块负责浮层选型与行为，本模块接入公共接口并使用其实现。已有实现足够时直接复用。组件任务可直接进入本 Skill，无需发现所有其他模块。

## 三类任务

| 任务 | 验证练习 | 可观察结果 |
| --- | --- | --- |
| 复用已有组件 | 用项目已有 Button/Field/Select 或等效组件实现指定区域，包含真实表单或操作路径 | 保留原导入/API/主题；值和事件载荷正确；真实结果驱动反馈；不增加重复封装/组件库 |
| 新增用途明确的变体 | 先比较已有尺寸/变体，仅补齐有证据的缺口，再检查普通与新增场景 | 名称/条件来自实际任务；组成结构与 token 映射协调；不改全局默认；适用的焦点、pending、disabled 和错误行为仍可用 |
| 跨页面使用 | 在密集列表和设置/详情等不同页面使用同一实现 | 公共导入与事件含义统一；明确选择密度/强调；无复制分叉；处理主题与内容差异；独立实例不意外共享状态 |

只编写 Skill 时，依据入口和参考进行真实场景推演，评估的是决策指导，不是已渲染的实现。实现任务则对变更代码及相关调用方运行适当且可用的检查。不能因为读过源码或元数据校验通过，就宣称完成运行验证。

## 检查实际变更

- **Token 继承：**检查真实来源与生成值，在每个受影响主题检查调用方。涉及 portal/Modal/消息时覆盖该路径，因为它可能脱离主题上下文。新增值按用途命名，不按截图色值命名。
- **接口一致性：**验证受控变化与初始值、事件载荷/时机、稳定行/选项键、原生属性与焦点访问。保留现有库命名，检查公共 API 变更的已有调用方。
- **内容与尺寸：**长文/多语言、大数、零/缺失值、重复标签、空数据和多个实例；在相关宽度与文字放大时不裁切。紧凑视觉控件仍需可用命中区域。
- **行为：**适用的键盘动作、焦点可见与返回、选中/展开状态、pending/防重复和恢复。测试真实成功与失败，动画完成不是操作成功。
- **设备与效果：**受影响的视口/输入方式、溢出/层级、减少动态效果与静态降级。一次浏览器检查不能宣称覆盖所有设备或辅助技术。
- **可维护性：**没有重复组件或平行 token 存储；不无故引入私有 DOM 样式依赖；示例符合当前接口；说明影响范围。

使用已有类型、构建、组件测试或合适的手动流程。只有能验证有意义的新行为时才添加针对性测试。文字规格可以没有代码示例；若含可执行示例，需使用声明的依赖运行并报告实际范围。

## 新参考到来时更新本 Skill

在作者的模块记录/研究档案中追加来源、实际观察、采纳规则、局部差异与检查。更新相关规则，不把每次新增材料累积成必读参考清单。原始图片、完整对话和研究留在分发包外。实际复用代码时保留来源版本与授权上下文。两套自制语言版本保持语义等价、标识和文件结构相同；完成语义审阅后再记录哈希。
