# 来源与方法摘要

本 skill 从37张设计图片、其中30组独立提示词，以及一段视频的8类构图中提炼规则。S/V 是研究时的来源编号，保留用于解释规则的由来。原图、完整提示词与逐图笔记属于制作档案，不随 skill 分发，也不是执行依赖。

## 参考组与可迁移的方法

| 编号 | 来源主题 | 已提炼的方法 |
| --- | --- | --- |
| S01–S07 | 透明顶栏、当前项展开、右轨、图标轨、提示与快捷动作 | 按入口数量、熟练度和可读空间选择导航；已有框架优先；导航与动作分开 |
| S08–S13 | 数据进入、拖拽、翻转、高亮、展开、聚合 | 用交互解释状态或减少操作成本；展示性效果按需启用，核心信息保持直接可见 |
| S14 | 任务协作工作台 | 任务状态、时间线、风险与人员形成D结构，排行榜不是必需模块 |
| S15 | 健康档案概览 | 单个对象的当前记录、历史趋势、检查与预约形成E+D结构 |
| S16 | 销售概览 | 核心经营结果→主趋势→订单摘要，支撑A结构 |
| S17–S18 | 财务与账户概览 | 余额与操作靠近，收支与流水关联，按视口选三栏或双栏，支撑E结构 |
| S19 | 人事与薪资状态 | 人员、负载、招聘与待处理队列，按角色组织D+A结构 |
| S20–S25 | 同一暖桃玻璃系统的交互与材质 | 玻璃是一种视觉层；内容结构先确定，精读区域保持稳定实底 |
| S26 | 编辑型数据叙事 | 结论/问题→证据→原因→行动，形成P01；结论需有数据支持 |
| S27 | 黑白极简 | 通过数字层级、对齐、细分隔和少量强调建立P02 |
| S28 | 柔和浅色运营分析 | 轻表面、低饱和系列与清楚标签形成P03，适配日常运营 |
| S29 | 模块化网格 | 依决策价值分配模块面积，形成P04；不机械等大分卡 |
| S30 | 深石墨用户行为分析 | 通过表面层级、路径选择和低饱和强调形成P05；深色不限定业务种类 |
| S31 | 自然数据与可持续发展 | 将基准、目标、趋势与资源结构组织成P06，避免生态装饰代替证据 |
| S32–S37 | 训练、种植、库存、片场、内容发现的导航实例 | 区分页面导航、实体切换与内容分类；选中态必须对应真实内容 |

S01–S06 分别对应透明顶栏、当前项展开文字、右侧竖轨、图标轨配大标题、图标提示和快捷动作；S07 为方案汇总。S08–S13 分别对应数据进入、重排、翻面、滑动高亮、展开详情和演示性收拢。

S20–S24 分别为液态高亮、光跟随、原位放大、命令面板和Dock；S25 提供暖桃玻璃参数。S32–S37 分别为图文侧栏、同类实体标签、品牌色图标轨、极简图标轨、顶部胶囊和内容分组菜单。

## 使用边界

- 来源标题混合了业务、沟通方式、布局与主题，不能直接当成互斥行业模板。任务结构见 [选型指南](selection-guide.md)，外观见 [视觉配方](visual-recipes.md)。
- 静态图不能证明刷新、键盘、窄屏或错误恢复已经实现；这些行为已补充到 [交互规则](interaction-patterns.md) 和 [数据与布局](data-and-layout.md)。
- 原样稿的数字、图表单位、目标与比例不能直接当计算依据。使用实际业务数据重新核对；没有依据时不生成结论、目标或AI建议。
- 只有暖桃玻璃配方保留原提示词的明确数值作为可选起点。其他颜色名称与形态描述是视觉归纳，不表示测量值或用户已确定的品牌偏好。
- 用户要精确复现特定图片时，以本次提供的图片为依据；普通设计直接使用本 skill 的规则。
