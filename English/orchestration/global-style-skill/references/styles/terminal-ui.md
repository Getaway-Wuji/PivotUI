# Terminal UI

Source: supplied reference board 05, label “Terminal UI”. Dimension: interface metaphor, typography, and theme.

## Observed

The hero uses a very dark field, bright green monospaced lettering, thin borders, a code-like panel, and an ASCII-style figure. Terminal imagery supplies the visual identity. A screenshot of this treatment does not demonstrate an actual terminal, command execution, or keyboard interaction.

## Suggested use and combinations

Consider the metaphor for developer tools, technical product introductions, or a bounded documentation example when it helps the audience understand the product. Separate genuine commands and output from decorative examples, and label illustrative content when necessary. A terminal panel can coexist with normal navigation, plain explanatory copy, and conventional buttons. Adopt the visual relationship between code and explanation without forcing every interface label into command syntax or replacing an existing brand theme.

## Limits, assets, and fallback

Check long commands, mixed languages, text wrapping, and contrast on the actual background. Monospaced display treatment should not make body copy or operational tables unnecessarily difficult to scan. Green decoration must remain distinct from success states. This direction can work with text and simple borders; fabricated live output adds no reliable product evidence. If the metaphor becomes distracting, retain one clearly identified code example within the normal product interface.
