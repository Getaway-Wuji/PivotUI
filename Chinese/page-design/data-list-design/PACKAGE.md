# 完整数据列表页设计包

版本：1.0.0。来源：基于用户指定的 Ant Design Pro 列表参考方向编写的内源方法。不捆绑上游源码或素材。Ant Design Pro 和 ProTable 仅作为外部参考，不声称固定了上游版本或完成运行验证；见[来源边界](references/layout-and-reference.md)。

以 `SKILL.md` 为入口。包内包含 UI 元信息和五份任务相关参考，其中包含注明版本的可携带规范摘编。独立使用时复制整个目录；不依赖同级技能、制作记录、研究文件或原始机器。共享方法归属见[基础规范](references/foundations.md)。

两版语言使用相同的 `data-list-design` 标识和文件拓扑。英文为维护源。许可：本内源包未单独声明许可证；遵循仓库适用条款，在必要时于再分发前取得明确说明。引用 Ant Design 不会使其许可证自动适用于本原创包。

现有集群 MCP 可发现该标准入口并读取选定资源，无需新增工具或注册格式。可运行制作期演示、验证报告和发布归档均在本包之外维护；整库基线与发布仍由整合者负责。
