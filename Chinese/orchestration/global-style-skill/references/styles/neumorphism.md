# Neumorphism / 新拟态

来源：用户提供的参考图板 02，原标签 **Neumorphism / 新拟态**。维度：柔和的表面起伏与组件外观。这是候选参考，不是产品默认风格。

## 观察到的证据

示例使用接近单色的浅表面、成对的明暗阴影、圆润形状，以及类似圆形计时器的对象。一些元素看起来凸起或凹入。静态图无法确定哪些控件处于按下、选中或可交互状态。

## 建议采用方式

可考虑用于小型、安静的控制面板，或柔和起伏有助于产品气质的局部装饰表面。保持阴影方向与背景关系一致。在起伏效果之外补充明确标签、可识别的控件形状和清楚的活动状态，不仅凭边缘凸起来表示状态含义。

## 组合与约束

可结合 `minimalism` 控制视觉密度。柔和表面削弱边界时，密集表单、重复业务操作和关键反馈应使用普通的高对比控件处理。文字、焦点、禁用和选中状态必须可区分，无须解读细微阴影。截图也没有证明这种处理适用于不同主题。

## 资产、成本与降级

图片资产需求少，但多背景下的状态设计与检查可能较费工。起伏效果不清楚或界面拥挤时，改用实色表面、明确边框和更简单的阴影，同时保留组件尺寸与语义。
