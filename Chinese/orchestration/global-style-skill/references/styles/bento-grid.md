# Bento Grid / 便当盒布局

来源：用户提供的参考图板 01，原标签 **Bento Grid / 便当盒布局**。维度：模块化布局，可独立与视觉风格组合。这是候选参考，不是产品默认风格。

## 观察到的证据

示例将较宽的主区块与较小的日历、任务、图片和指标区块组合起来。圆角边界与浅强调色背景统一了不同尺寸的区域。截图表现分组与比例，不能证明实时组件、拖拽或窄屏排列方式。

## 建议采用方式

可考虑用于功能总览、产品摘要，或内容优先级和面积需求确实不同的 Dashboard。每个区块承担一个连贯用途，面积由信息需求决定，保留定义、操作和必要比较。表格或连续叙事可能更适合通栏区域，不必强行拆块。

## 组合与约束

可结合 `minimalism`、`swiss` 或克制的 `dark-tech`。区块几何关系不要求使用粉彩、大圆角，也不要求所有区域都变成卡片。先确定阅读顺序，再设计窄屏堆叠。避免孤立的装饰指标、卡片套卡片，以及把相关标签和值拆散的重排。业务内容分组仍由页面负责人决定。

## 资产、成本与降级

基础布局成本较低，专用图表和组件各自增加复杂度。没有合适的图片或组件时，使用真实文字内容，不编造指标填空。可降级为有序段落或简单网格，同时保留优先级和关联关系。
