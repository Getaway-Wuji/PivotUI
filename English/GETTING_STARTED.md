# Getting started with PivotUI

Use this complete edition with a file-capable agent or connect its local MCP server. Start with [the orchestrator](orchestration/design-orchestrator/SKILL.md), then let it select relevant modules. Keep this folder structure intact. Do not connect both language editions under the same skill names.

For MCP, install Python 3.11 or later, follow [the server installation and configuration guide](mcp/skill-cluster/README.md), then instruct the host to discover metadata and load `design-orchestrator` before interface tasks. The server provides read-only instructions; the host applies them with its own tools.
