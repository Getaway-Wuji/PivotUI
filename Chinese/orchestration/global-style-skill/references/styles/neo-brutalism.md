# Neo-Brutalism / 新粗野主义

来源：用户提供的参考图板 02，原标签 **Neo-Brutalism / 新粗野主义**。维度：鲜明组件语言与活泼图形对比。这是候选参考，不是产品默认风格。

## 观察到的证据

示例使用明亮平涂色块、粗深色描边、硬质偏移阴影、粗体文字，以及重叠的窗口式插图。相较旁边的 Brutalism 示例，它更鲜艳，框架更明显。可见重叠不能证明拖拽行为或真实交互窗口。

## 建议采用方式

可考虑用于活泼的创意产品、活动页面和局部表现性功能。保持描边与阴影系统一致，让一个主要行动入口具有明确优先级。区分装饰窗口和真实对话框、控件。更强的颜色应服务于有意义的层级，不使所有区域争夺同等注意力。

## 组合与约束

可结合 `bento-grid` 进行模块分组，或结合 `hand-drawn` 添加有限插画。品牌装饰应与错误、警告、成功的含义分开。密集业务页可在标题或强调区域保留少量特征，同时减少重复粗框。检查饱和色块内文字可读性，使焦点与装饰边框明确区分。

## 资产、成本与降级

平面形状和 CSS 阴影可控制资产成本，定制插图则增加工作。布局拥挤时减少重叠和强调色表面。简化后的描边表达应保留相同控件、阅读顺序和内容层级。
