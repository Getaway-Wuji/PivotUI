# 选择与任务

## 明确选中集合

只支持产品能够实际执行的范围。简单列表可以跨页选择明确 ID，无需提供全部匹配结果选择。

| 范围 | 表达方式与可见含义 |
| --- | --- |
| 当前页 | 表头复选框选择当前已加载页中符合条件的记录；计数不含不可选行 |
| 跨页明确记录 | 保存稳定的选中 ID，展示总数并提供查看／清空路径；本页复选框仅反映可见且符合条件的行 |
| 全部匹配结果 | 在本页选择后由用户明确切换；使用查询快照／令牌，或说明实时查询语义，并展示数量和排除项 |

正确呈现选中、未选中和半选状态。在不泄露禁止信息的前提下，解释可见行不能选择的原因。切换到全部结果时，说明包含什么，以及后来到达的记录是否包含在内。破坏性操作优先使用服务端确定的快照或执行前范围确认；客户端已加载 ID 列表不等于全部结果。

改变筛选必须清空选择，或明确核对调整，不能悄然扩大范围。排序／翻页需要一致的保留策略。处于全部结果范围时，取消勾选一条记录会新增排除项，不能悄然切回已加载页。匹配数量、符合操作条件的数量和选中数量不同时，应区分展示。

## 批量任务生命周期

提交前展示操作、范围／数量、适用条件和重要影响。沿用按风险选择确认方式的规范：不可逆删除使用 Modal，低风险就近确认可以使用 Popconfirm。不能用 Tooltip 承载确认。权限由后端执行；禁用界面用于解释，不构成安全授权控制。

保存不可变的提交范围并阻止重复提交。长任务应有可持续查询的任务标识／状态和返回路径；离开页面或关闭视图不等于取消。只有后端能够兑现时才提供取消。超时结果未知时，先通过状态查询／幂等机制确认，再决定是否重试可能已经成功的操作。

分别报告成功、失败、跳过和结果仍未知的记录。在持久结果区域保留原因及可用的失败记录列表；按共享规范，错误不进入 Toast。从重试选择中移除成功 ID，保留符合条件且可重试的失败项，并仅重试这些 ID。重新核查授权和已变化记录。不承诺实际不支持的撤销，也不为凑齐结果重新处理成功项。

操作完成后刷新受影响的数据、数量和有效分页，同时保留查询。如果触发控件消失，将焦点移至持续结果标题或其他合理位置。

## 导出单独确定范围

为支持的导出范围命名：当前页、选中记录或全部匹配结果。不能从笼统的“导出”标签或过期选择推断范围。执行前让用户理解范围、数量／估计数量、包含字段和顺序。可见列与导出字段是不同选择；说明导出采用当前列还是预定义字段结构。权限和相关查询快照需一致应用。

大型导出应保留任务／状态路径及实际下载结果，并在支持时提供重试和过期处理。生成文件或服务端任务完成才是成功证据，计时器结束不是。防止电子表格兼容导出中的文本字段被解释为公式，并遵循产品的数据处理规则。演示导出必须标明合成数据及仅在本地执行的行为。
