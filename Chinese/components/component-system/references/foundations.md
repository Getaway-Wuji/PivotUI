# 可移植共用约定

摘编 Shared Interface Design Foundations 0.2 与 Orchestration 0.2 中的必要规则，并补充组件层面的应用；核对日期为 2026-11-14。本文件支持独立使用。在目标项目中，优先遵循其当前明确要求及权威设计约定，无需访问原制作路径。

- 根据用户需要理解、判断和执行的任务组织层级。先用位置、分组、尺寸和间距，再增加装饰。同一产品内保持相同语义与组件行为一致；有意义的差异需明确适用条件。
- Token 属于目标产品，保留一处可维护来源。全局风格能力可用时生成/校验值，主控归并。已有主题、字体、颜色、圆角与组件库优先于参考默认值。新增公共值须记录用途及影响。
- 复用已有组件和受支持的扩展点。页面主力负责业务结构，组件实现承载约定的交互与设备规则。缺少可选 Skill 不阻塞普通任务，也不声称调用了不存在的 Skill。
- 补齐适用状态及有意义的空白、错误、加载内容。失败时保留输入，处理中防止重复操作；关键流程可用键盘，控件有名称和可见焦点，并处理长内容与窄屏布局。
- 减少动态效果时仍可完成界面操作。对外营销效果不成为业务工具的默认。本集群中 `gpt-taste` 仅用于对外营销，`ui-ux-pro-max` 提供研究与建议。
- 静态截图不能证明隐藏状态或精确尺寸。记录估计与补充决定。来源声明、场景推演和实际运行检查应分别说明。

## 浮层与消息兼容

`floating-components` 可用时，读取其当前相关规则并复用已有实现。以下为独立使用保留本集群的当前区分，是项目约定，不是所有组件库的通用定义：

| 组件 | 当前用途 |
| --- | --- |
| Tooltip | 短暂的补充说明；必需指引不能仅在悬停时出现，也不用作交互操作容器 |
| Toast | 轻量成功结果反馈；错误和需要处理的警告留在持久界面中 |
| Alert | 持久的重要提示或错误，必要时提供恢复操作 |
| Modal | 不可逆/高风险确认或复杂信息，不用于普通简单确认 |
| Popconfirm | 确有帮助的局部低风险确认，不代替高风险 Modal |
| Drawer | 保留周边上下文的较大编辑任务；简单表单内联，独立全屏流程使用页面 |

复用成熟浮层基础能力处理焦点、Escape、背景交互及合理的焦点返回。是否限制焦点取决于实际模态语义，而非侧面板外观。处理中、关闭和取消的行为遵循真实操作；关闭不意味着服务器已取消任务。保留错误与草稿，跨 portal 继承主题，并协调层级及滚动边界。目标项目的明确约定不同时，记录所采用的覆盖规则，不维护两套竞争行为。
