# Brutalism / 粗野主义

来源：用户提供的参考图板 02，原标签 **Brutalism / 粗野主义**。维度：粗粝的图形层级与直接表达。这是候选参考，不是产品默认风格。

## 观察到的证据

示例结合超大粗体、鲜明的黑白配色、细分隔线、粗粝混凝土照片和朴素的矩形操作按钮。表现力来自尺度与材质对比。截图没有显示故意损坏的导航或特殊交互。

## 建议采用方式

可考虑用于文化项目、表现性作品集，或需要强烈直接表达的品牌页面。选择一个主导的文字表达和明确的内容顺序，让可见结构与真实图片承担表现力。即使展示文字十分强烈，功能控件也应容易辨认。

## 组合与约束

可结合 `swiss` 的对齐或 `editorial` 的阅读顺序。`neo-brutalism` 带来的是另一种鲜艳、描边鲜明的组件语言，应有意选择，不能把两者名称视为互换。避免裁掉有意义的标题、难读的全大写段落、任意重叠和破坏任务的滚动。粗粝外观不需要牺牲内容与操作的可达性。

## 资产、成本与降级

基础实现可以较简单，但有特点的字体与照片需要认真选择。缺少戏剧性资产或字体时，用项目资源保持强层级、分隔线和克制配色。窄屏应适配大标题，而非无差别缩小所有内容。
