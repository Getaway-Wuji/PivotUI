# 组件组成与家族选型

只读当前任务涉及的家族。下列结构指导组合，优先使用已安装组件库提供的等效部分。

| 家族 | 可用组成结构 | 选型与接口决定 | 状态与复用检查 |
| --- | --- | --- | --- |
| Button / 图标操作 / 分裂式操作 | 操作表面、标签、可选前后图标、进行中提示；分裂式操作具有单独菜单触发器 | 动作用按钮，导航用链接。纯图标需名称。只有明确的默认操作及相关备选项才使用分裂式操作。保留原生提交行为 | Pending 由真实工作驱动，不由动画驱动；防止重复执行；焦点与标签清楚；菜单触发器独立命名 |
| Input / Field / textarea | 标签、控件、可选前后缀、帮助、错误；可选计数或清空操作 | Field 提供关联和布局，控件接入现有表单状态。值与显示格式分开。清空/显隐控件是独立操作 | 失败后保留输入；关联标签/帮助/错误；区分 readonly/disabled/invalid；长标签和错误文案可展开 |
| Select / combobox / 选项组 | 标签、触发器或可编辑输入、当前值、指示符、浮层、选项；可选清空、说明及搜索/加载区 | 简单短列表可用原生 Select；确有搜索需求再用 combobox；少量同时可见的备选项可能适合 radio。明确单选/多选、本地/远程搜索、稳定键与标签、空值 | 键盘选择/Escape；焦点与选中分开；重复标签；清空语义；加载/错误/无匹配分开；浮层裁切及焦点返回 |
| Checkbox / radio / switch | 控件、可见标签、可选说明；checkbox 可有 mixed 状态 | Checkbox 表示独立选择，radio 表示一组中的单选，switch 在产品采用该模式时表示即时设置。不能只凭形状选择 | checked/mixed/disabled 约定正确；分组标签；异步变化与失败恢复对应真实持久化行为 |
| Tag / badge / chip | 文字与可选状态标记、图标、数量或移除操作 | 区分被动状态、可选筛选和可移除值。被动标签不必获得焦点；可选 chip 需要控件语义 | 颜色同时配文字；选中/移除行为明确；移除控件有名称；换行/溢出和相邻目标仍可操作 |
| Card / surface | 可选媒体、标题/说明、正文、元信息、操作/页脚 | 为真实内容分组添加边界。组合区域而非堆积页面专属 props。改变表面处理不一定要新建组件。可点击卡片有明确主操作 | 避免嵌套链接/按钮和含混点击区；次级操作独立；长内容；表面与前景色配对；区域内边距一致 |
| Table / 数据区域 | 标题或名称、表头、行/单元格、可选选择、工具栏、分页、空白/加载/错误区 | 数据使用原生 table 或成熟表格组件；只有需要且实现更丰富键盘模型时才用 grid。明确列、行键、排序/筛选/分页与选择归属 | 排序/分页后键稳定；零与缺失值分开；明确跨页选中键；宣告排序状态；单元格按钮可用；窄屏溢出保留含义 |
| Navigation / tabs / pagination | 地标/分组、项目标签、可选图标/计数、当前/选中标记、溢出控件 | 链接导航，tabs 切换相关面板，menu 呈现动作。页面主力定义目的地与层级，组件实现接口约定。普通站点导航不套用 menu 角色 | 当前/激活状态与焦点不同；键盘与面板关联；长标签；收纳/溢出保留访问；独立实例不共用全局 active index |
| Modal / Drawer / Popconfirm | 已有浮层外壳、标题/说明、正文、操作、关闭/返回路径；可选触发器 | 复用已有浮层能力与选型规则。组件负责人接入内容插槽、open 状态、主题及焦点访问；页面负责业务操作 | Modal 背景/焦点约定；portal 主题与层级；嵌套浮层；草稿/进行中/关闭规则；错误可读；焦点回到合理位置 |
| Tooltip / Toast / Alert | 关联说明或结果、可选图标及适当操作 | 遵循项目的浮层/消息区分。必需指引可见且有对应关联；持续错误需要持久界面 | Tooltip 不作为交互菜单；成功反馈对应真实结果；定时器不隐藏未解决错误；宣告和关闭不抢焦点 |

## 重要的组合选择

- 替换 Field 内部控件时，仍保留标签与错误关联。只有好看外观、没有表单绑定的输入框不是完整可复用字段。
- 可编辑远程选择需分开输入查询、已提交的选择和已获取选项。通过现有数据层取消或忽略过期请求；标签重复或选项重载时仍保留选中标识。
- 选中卡片需要真实可选控件或等效的正确语义。阴影和 `selected` class 本身不能完成选择。使用 checkbox/radio 或合适链接/按钮，避免把交互子元素包进另一个控件。
- 表格密度使行与嵌入控件整体变化。分页、服务端筛选、跨页选择保留和批量操作须对操作的数据集有一致理解。
- 视觉暗示与行为一致：拖动手柄对应的任务需有非指针操作路径；悬停显示不能让键盘/触屏用户失去唯一操作入口。复杂模式优先复用成熟基础能力，不靠截图重新发明焦点和选择机制。

实现底线来自项目共用规范。构建相关行为时可查阅 [WAI Button](https://www.w3.org/WAI/ARIA/apg/patterns/button/)、[WAI Combobox](https://www.w3.org/WAI/ARIA/apg/patterns/combobox/) 和 [WAI Table](https://www.w3.org/WAI/ARIA/apg/patterns/table/)。它们描述不同模式，不是对某个库或成品的认证。浮层约定摘编见[共用约定](foundations.md)。
