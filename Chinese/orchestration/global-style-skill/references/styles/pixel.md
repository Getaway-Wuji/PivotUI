# Pixel / 像素游戏风

来源：用户提供的参考图板 04，原标签 **Pixel / 像素游戏风**。维度：点阵式插画与游戏启发的展示语言。这是候选参考，不是产品默认风格。

## 观察到的证据

示例使用块状景观与角色、像素形展示字、明亮蓝绿区域，以及类似游戏 HUD 的爱心或金币。图片不能证明可玩的游戏、实时分数、动画或实际奖励。

## 建议采用方式

可考虑用于游戏、怀旧社区、活泼作品集或主题活动。保持像素尺度与图像处理一致。有选择地使用展示字，说明和密集内容使用普通易读文字。除非产品确实定义含义与行为，否则游戏指示物应作为装饰图像。

## 组合与约束

可结合 `retro-web` 提供怀旧框架，或结合 `minimalism` 突出像素作品。不要用编造的爱心和金币取代业务状态、进度或货币。无论视觉网格如何，都应保留可识别按钮、合适目标尺寸、焦点和文字替代。检查混合语言内容，拉丁像素字体不一定覆盖所需字符。

## 资产、成本与降级

定制精灵图与一致的像素缩放需要仔细准备资产。静态场景已经能承载观察到的方向。缺少合适字体或精灵图时，可保留小范围像素装饰，使用普通网页原生文字与控件，不将整个界面栅格化。动画属于独立范围。
