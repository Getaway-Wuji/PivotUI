# Install PivotUI: copy two folders

## Codex, DSH / DeepSeek Harness, or Cursor

1. **Extract the ZIP**, then open the extracted `PivotUI-English` or `PivotUI-Chinese` folder. You will see `.agents`, `.pivotui`, and this guide.
2. **Copy both `.agents` and `.pivotui` into your project folder.** Select the two folders together, copy them, open your project folder, and paste. Copy the whole folders; you do not need to open them or move individual files.
3. **Open that project in your Agent and start a new chat.** Select `pivotui` and describe the interface you want to build.

Your project should now look like this:

```text
your-project/
├── .agents/
├── .pivotui/
└── your other project files, if any
```

That is the complete installation. There is no install button or command to run.

**Which folder is the project folder?** It is the outer folder you open in your coding tool to work on this project. It may contain files such as `package.json` or a `src` folder, but an empty project folder is fine too. Put the two folders directly inside it, not inside another `PivotUI-English` or `PivotUI-Chinese` folder. This copy installs PivotUI for that project.

**Already have a `.agents` or `.pivotui` folder?** Merge the copied folders into the existing ones. Keep other skills and settings. If your file manager asks to replace files with the same name, check whether they belong to an earlier PivotUI installation and preserve any edits before replacing them.

## Claude Code

1. In the **extracted download**, rename `.agents` to `.claude`.
2. Copy both `.claude` and `.pivotui` into your project folder. If the project already has `.claude`, merge into it and keep its other files. Do not rename an existing `.agents` folder in your project.
3. Open that project in Claude Code, start a new chat, and select `pivotui`.

## Check the copy

For Codex, DSH and Cursor, the project should contain `.agents/skills/pivotui/SKILL.md`. For Claude Code, the same file should be at `.claude/skills/pivotui/SKILL.md`. The full library is in `.pivotui/libraries/{{LIBRARY_NAME}}/`.

Keep both copied folders together when moving the project. If the two folders are not visible after extraction, turn on hidden-file display in your file manager and look again.

The single `pivotui` entry selects from the library's 27 module entries. See the [module list](.pivotui/libraries/{{LIBRARY_NAME}}/README.md), [license](.pivotui/libraries/{{LIBRARY_NAME}}/LICENSE), and [third-party notices](.pivotui/libraries/{{LIBRARY_NAME}}/THIRD_PARTY_NOTICES.md). No other PivotUI ZIP is needed.
