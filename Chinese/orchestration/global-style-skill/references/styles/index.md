# 风格参考索引——40项

用索引定位候选，再只读相关卡片。七个浏览分类可以交叉：布局、表面或素材处理可以搭配某种视觉气质，并非互斥的整站模板。任务没有要求重新考虑时，继续沿用当前主题。开放选择按[选型规则](../style-selection.md)处理。

条目保留用户8张静态图板的标签，每张5项。卡片注明图板编号，区分可见线索与建议适配方式。原图保留在制作档案中，本包不依赖本机下载目录或远程网站。图板不能证明精确 token 或实际运行行为；标签是参考词汇，并不代表当前潮流的完整清单。
