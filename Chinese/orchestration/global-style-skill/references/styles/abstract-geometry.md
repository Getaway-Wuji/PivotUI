# Abstract Geometry / 抽象几何风

来源：用户提供的参考图板 07，原标签“Abstract Geometry / 抽象几何风”。维度：图形形状与图片构图。

## 观察

粗重深色字体、蓝色点缀、圆与矩形、建筑摄影在浅色背景上组成首屏。形状与照片形成图形配合，而非数据标记。这一处理与同批图板的原色 Bauhaus 示例有区别，但不能由此建立严格的历史分类。

## 建议用途与组合

品牌介绍、作品集区块、抽象产品概念或编辑式开场可考虑少量几何图形。让形状的对齐与尺度强化信息，各有明确作用。可与分屏布局、克制摄影或有力字体组合；单个主要构图通常比多套无关形状更易读。适当保留已有项目颜色，业务结构仍由对应页面模块负责。

## 限制、资产与降级

形状不能遮挡内容、伪装为不可用控件，或在没有数据时暗示数量关系。重要文字避开复杂交叠区域，按实际尺寸检查裁切构图。简单 SVG 或 CSS 几何图形成本较低；摄影需合适资产，三维渲染和动画可选。构图适配脆弱时，降为一个几何点缀与普通图片框，保留原有阅读顺序和层级。
