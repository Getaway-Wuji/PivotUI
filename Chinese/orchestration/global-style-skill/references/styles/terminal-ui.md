# Terminal UI / 程序员终端风

来源：用户提供的参考图板 05，原标签“Terminal UI / 程序员终端风”。维度：界面隐喻、字体与主题。

## 观察

首屏使用很深的背景、亮绿色等宽文字、细边框、类似代码的面板与 ASCII 风格图案，以终端意象建立视觉识别。该处理的截图不能证明真实终端、命令执行或键盘交互能力。

## 建议用途与组合

当终端隐喻有助于受众理解产品时，可用于开发者工具、技术产品介绍或局部文档示例。区分真实命令、输出与装饰示例，必要时标明示意内容。终端面板可以和常规导航、直白说明、普通按钮并存。借用代码与解释之间的视觉关系，不必让全部标签都变成命令语法，也不应因此替换已有品牌主题。

## 限制、资产与降级

核查长命令、中外文混排、换行及实际背景上的对比度。等宽展示不能让正文或业务表格变得难以扫描。绿色装饰需要与成功状态保持区别。文字与简单边框即可完成这一方向；虚构实时输出不能提供可靠产品证据。隐喻干扰任务时，在正常产品界面内仅保留一个身份明确的代码示例。
